# security-engineering — provenance

Synthèse éditoriale issue de la recherche relue du 7 septembre 2026. Les procédures des phases sont notre traduction dans le contrat v1, pas une certification des organismes cités. Vérifier la version et l’applicabilité d’une norme ou documentation évolutive avant d’en tirer une exigence actuelle.

- [NIST SP 800-218 SSDF 1.1](https://csrc.nist.gov/pubs/sp/800/218/final), NIST, pratiques de développement sécurisé intégrables à un SDLC ; consultée le 2026-09-07.
- [NIST Cybersecurity Framework 2.0](https://www.nist.gov/publications/nist-cybersecurity-framework-csf-20), NIST, résultats de cybersécurité et caractère non prescriptif du cadre ; consultée le 2026-09-07.
- [OWASP Application Security Verification Standard](https://github.com/OWASP/ASVS), OWASP, exigences ouvertes pour concevoir, développer et vérifier des applications web ; consultée le 2026-09-07.
- [OpenSSF Scorecard](https://github.com/ossf/scorecard), OpenSSF, contrôles de santé de sécurité et critères de remédiation pour les dépôts ; consultée le 2026-09-07.
