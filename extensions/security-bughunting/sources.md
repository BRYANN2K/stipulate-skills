# security-bughunting — sources

Editorial synthesis of standard, publicly documented vulnerability-class knowledge, reviewed on 2026-10-11. The phase procedures are our adaptation to the v1 contract, not certification by the cited organizations. Verify the version and applicability of evolving standards before deriving a current requirement.

- [OWASP Application Security Verification Standard](https://github.com/OWASP/ASVS), OWASP; verification requirements for designing, developing, and testing applications; consulted 2026-10-11.
- [OWASP Top 10](https://owasp.org/www-project-top-ten/), OWASP; the most common web application risk categories; consulted 2026-10-11.
- [CWE — Common Weakness Enumeration](https://cwe.mitre.org/), MITRE; a catalog of software weakness types for mapping classes; consulted 2026-10-11.
- [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/), OWASP; defensive guidance per weakness class; consulted 2026-10-11.

Inspiration: the structure of a per-class hunting pass was informed by Claude-BugHunter by Sachin Sharma (https://github.com/elementalsouls/Claude-BugHunter), code under MIT and documentation under CC BY 4.0. This package is authored from the standard sources above; it does not copy or redistribute that project's skills, and it keeps a strictly defensive, authorized scope.
