# DevOps skills

Operational workflows for delivering software safely and learning from production behavior.

| Skill | Focus |
|---|---|
| [devops](devops) | Route broad delivery and operations outcomes to CI/CD, GitOps, or incident investigation while preserving cross-domain handoffs |
| [sre-incident-investigation](sre-incident-investigation) | Incident triage, investigation, mitigation, and learning |
| [gitops-operations](gitops-operations) | Static GitOps audits and read-only live debugging |
| [delivery-pipeline-engineering](delivery-pipeline-engineering) | CI/CD, supply-chain controls, and progressive delivery |
