## Short Description (479 of 500 characters)

```text
Spec-driven orchestration for Claude Code. You and an orchestrator agree on a spec with acceptance criteria, and nothing is built until you press Approve. Each task then goes to a worker with its own model and effort; writers run in isolated git worktrees and can only touch the files they own. A separate session checks every criterion, and the change ends as one local commit. Live pane and band in the terminal and desktop app. For developers who want AI work they can review.
```
