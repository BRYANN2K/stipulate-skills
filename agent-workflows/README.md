# Agent Workflows

Cross-cutting skills that make agent execution, verification, handoff, and reporting more reliable across domains.

| Skill | Use it for |
|---|---|
| [agent-workflows](agent-workflows) | Route broad agent-workflow requests to repository instructions, truthful completion evidence, or explicitly requested focus-friendly presentation |
| [verified-completion](verified-completion) | Require fresh, requirement-level evidence before claiming work is complete, working, verified, deployed, or published |
| [agents-md-authoring](agents-md-authoring) | Create, adapt, audit, and scope evidence-backed `AGENTS.md` instructions across software, infrastructure, platform, data, and documentation repositories |
| [focus-friendly-delivery](focus-friendly-delivery) | Adapt authorized work and explanations into ADHD-friendly, action-first, exact, scannable delivery when explicitly requested or established as a user preference, without replacing safety, domain workflow, or evidence |
