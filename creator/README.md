# Creator

Skills that help builders preserve real work, find useful ideas, and communicate without handing their voice to an agent.

| Skill | Use it for |
|---|---|
| [creator-workflows](creator-workflows) | Route creator work between private evidence capture and opt-in prose auditing while keeping drafting and publication separately authorized |
| [build-in-public-journal](build-in-public-journal) | Maintain a private evidence log and identify safe, platform-specific content opportunities without drafting posts |
| [prose-pattern-audit](prose-pattern-audit) | Audit completed drafts for contextual assistant residue, empty scaffolding, repetitive cadence, vague validation, generic closers, and unsupported emotion, experience, or stance; detect by default and edit only on request |
